⭐ 내 즐겨찾기

    아직 즐겨찾기한 문장이 없어요. 각 문장의 별표를 눌러 저장해 보세요.

    이 문장들은 어떻게 정리했나요

    실제 여행에서 부딪히는 순간을 기준으로 식당, 숙소, 편의점/가게, 카페, 교통, 길찾기, 긴급상황, 쇼핑/면세까지 8개 상황으로 나눠 정리했습니다. 각 문장은 한글 뜻, 히라가나, 원문, 한글 발음 표기를 함께 보여줘서 일본어를 몰라도 화면을 그대로 보여주며 의사소통할 수 있도록 만들었습니다. 자주 쓸 것 같은 문장은 즐겨찾기에 저장해두면 여행 중 빠르게 다시 찾을 수 있습니다.

    발음 표기는 어떤 기준인가요?

    일본어 초심자도 바로 읽을 수 있도록 한글로 최대한 실제 발음에 가깝게 표기했습니다. 장음이나 촉음처럼 한글로 완벽히 표현하기 어려운 부분은 원어민 발음과 약간 차이가 있을 수 있어, 정확한 발음은 히라가나 표기를 참고하시는 걸 권장합니다.

    인터넷이 안 되는 상황에서도 쓸 수 있나요?

    홈 화면에 앱으로 설치해두면 서비스워커가 페이지를 미리 저장해둬서, 데이터가 안 터지는 상황에서도 이미 방문했던 페이지는 열람할 수 있습니다.

    즐겨찾기한 문장은 어디에 저장되나요?

    브라우저의 로컬 저장소에만 저장되며 서버로 전송되지 않습니다. 브라우저 데이터를 지우면 즐겨찾기 목록도 함께 사라집니다.

    표기된 한글 발음은 실제 일본어 발음과 다를 수 있는 참고용 표기입니다.
