필요한 순간, 바로 꺼내 쓰는 작은 도구들을 만듭니다.

어떤 프로젝트인가요

SY Project는 회원가입이나 로그인 없이, 필요한 계산 하나만 빠르게 끝낼 수 있도록 만든 개인 프로젝트입니다. 계산기부터 개발자 도구, 여행 가이드까지 필요할 때마다 도구를 하나씩 늘려가고 있습니다.

운영 원칙

  • 회원가입, 로그인 없이 누구나 바로 사용할 수 있습니다.
  • 입력한 정보는 서버로 전송되지 않고, 브라우저 안에서만 계산됩니다.
  • 모든 도구는 무료로 제공됩니다.

제공 중인 도구

  • 만나이 계산기 — 만나이·한국나이·띠·별자리 계산
  • 진수 변환기 — 2/8/10/16진수 실시간 변환, 비트 연산
  • JSON ⇄ CSV / YAML 변환기 — 데이터 포맷 실시간 상호 변환
  • UUID / 랜덤 문자열 생성기 — UUID v4/v7, 암호화 키 생성
  • 컬러 코드 변환기 — HEX/RGB/HSL 변환, 팔레트 추출
  • 글자 검토대 — 글자 수 세기, 두 글 비교(TXT·DOCX 지원)
  • 퇴사일 계산기 — 목표 저축액 기반 퇴사 가능일, 실수령액 계산
  • 반려동물 나이 계산기 — 강아지·고양이 나이 환산, 사료량 계산
  • 일본 여행 필수 회화 — 상황별 일본어 문장 모음
  • 이름 획수 궁합 — 전통 방식 이름 궁합 계산
  • 꽃잎 점 — 그렇다 아니다로 답하는 Yes or No 점치기
  • 털어버리기 — 마음에 담아둔 말을 적고 놓아보내는 감정 정리 도구
  • 상식 퀴즈 — 역사·과학·문화·지리·스포츠 무작위 4지선다 퀴즈
