JSON, CSV, YAML은 언제 어떤 걸 써야 하나요

JSON은 API 통신과 중첩된 객체 구조 표현에 강하고, CSV는 엑셀·스프레드시트로 여는 표 형태 데이터에 적합하며, YAML은 설정 파일처럼 사람이 읽고 수정하기 편한 형식입니다. 이 도구는 JSON의 중첩 객체를 CSV로 변환할 때 자동으로 `주소.도시`처럼 점(.) 표기법으로 평탄화(flatten)하고, 반대로 CSV나 YAML을 JSON으로 되돌릴 때는 이 표기법을 다시 중첩 구조로 복원합니다.

중첩된 배열은 CSV로 어떻게 변환되나요?

배열 값은 평탄화하지 않고 문자열화된 JSON(예: ["a","b"])으로 한 셀에 저장됩니다. 반대로 CSV를 JSON으로 변환할 때 대괄호나 중괄호로 시작하는 셀은 자동으로 JSON으로 파싱을 시도합니다.

여러 행(배열)이 있는 JSON도 변환되나요?

네. 최상위가 배열이면 각 항목을 한 행으로, 객체 하나면 한 행짜리 표로 변환합니다. 항목마다 키가 달라도 전체 키를 모아 헤더로 만들고 없는 값은 빈 칸으로 채웁니다.

변환한 파일을 그대로 시스템에 써도 되나요?

표준 JSON.stringify, js-yaml, PapaParse 라이브러리를 사용해 각 포맷의 표준 문법을 따르므로 대부분의 파서와 호환됩니다. 다만 필드명에 특수한 규칙이 있는 시스템이라면 결과를 확인 후 사용하는 걸 권장합니다.
