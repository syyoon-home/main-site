The Answer Is
그렇다

꽃잎점은 어떤 놀이인가요

꽃잎점은 "그 사람이 날 좋아한다, 안 좋아한다"를 꽃잎을 하나씩 세며 점쳐보던 오래된 민간 놀이에서 따온 재미 요소입니다. 궁금한 것을 질문으로 입력하면, 꽃잎이 떨어질 때마다 그렇다·아니다가 번갈아 카운트되고, 마지막 꽃잎이 가리키는 쪽이 답이 됩니다. 심리학적·통계적 근거가 있는 예측이 아니라, 결정을 앞두고 마음을 가볍게 들여다보는 용도로 즐겨주세요.

같은 질문을 다시 하면 답이 달라지나요?

네, 매번 꽃잎 개수와 순서가 새로 무작위 배정되기 때문에 같은 질문이라도 다시 시도하면 다른 답이 나올 수 있습니다.

입력한 질문이 저장되나요?

아니요. 질문 내용은 서버로 전송되지 않고 화면 안에서만 사용되며, 페이지를 벗어나면 사라집니다.

자동으로 떨구기는 어떻게 다른가요?

꽃잎을 하나씩 직접 누르는 대신 자동으로 빠르게 진행해주는 기능으로, 결과 확인 과정 자체는 동일합니다.
